# carinneleibovici.com

Site bilingue (FR / EN) de Carinne Leibovici, psychologue clinicienne, hébergé sur GitHub Pages.

- Pages françaises à la racine, pages anglaises dans `en/`.
- Les pages HTML sont générées par `build.py` : modifier les textes dans ce fichier (`t("français", "English")`), puis lancer `python3 build.py`.
- Styles : `assets/style.css`. Photos : `assets/`.
- `CNAME` relie le site au domaine www.carinneleibovici.com.
